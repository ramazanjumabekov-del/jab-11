# Видеособеседование 1 на 1

Простой видеозвонок «один на один» на React + Vite + WebRTC. Сигналинг идёт через WebSocket, видео — напрямую между браузерами.

## Запуск

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # сборка в docs/ для GitHub Pages
npm run lint
```

## Как пользоваться

Открой приложение в двух окнах (или на двух устройствах) и в каждом:

1. **Включить камеру** — разреши доступ к камере и микрофону.
2. **Подключиться** — соединение с сигнальным сервером.
3. **Позвонить** — нажми в одном из окон. «Завершить звонок» разрывает связь, «Выйти» отключает всё и выключает камеру.

Камера работает только по HTTPS или на `localhost`.

## Структура

```
src/
├── main.jsx                 # точка входа
├── App.jsx                  # собирает хуки и компоненты
├── config.js                # адрес сигнального сервера, ICE, таймаут звонка
├── hooks/
│   ├── useCamera.js         # локальная камера и микрофон
│   └── useVideoCall.js      # WebSocket-сигналинг и RTCPeerConnection
├── components/
│   ├── VideoTile.jsx        # плитка с видео
│   ├── StatusBar.jsx        # статус и этапы подключения
│   └── Controls.jsx         # кнопки управления
└── styles/index.css         # стили (светлая и тёмная тема)
```

## Деплой на GitHub Pages

`npm run build`, закоммитить папку `docs/`, затем в настройках репозитория: Settings → Pages → Branch `main`, папка `/docs`.
